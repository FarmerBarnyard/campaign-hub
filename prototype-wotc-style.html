WotC-style prototype — Step 0

Standalone, not wired into the app's router — for visual sign-off only, before any of the 4 real generators are touched.

1. Pictorial buildings

drawPictorialBuilding (lib/pictorial-buildings.js) at normal settlement scale, vs. the same buildings scaled down to the overworld marker size (9-18px). The plan recommends overworld markers stay abstract silhouettes rather than using this — compare the two rows below to judge that call directly instead of just asserting it.

Settlement scale
Overworld marker scale (9-18px)

2. Organic roads

strokeOrganicRoad (lib/organic-roads.js): dirt (village lane), stone (town/city street), and a thinner overworld-scale ribbon, all on the same curving centerline.

3. Numbered badge + legend

drawNumberedBadge + renderKeyLegendPanel (lib/keyed-legend.js) — same markup/CSS as the dungeon's existing room-key panel, generalized for settlement POIs.

4. Mock village cluster

A hand-placed stand-in for the full sparse-cluster algorithm: 2-3 loose groups of pictorial buildings, each oriented to face its nearest dirt path, real gaps between clusters (not one packed block).

5. Generation-progress overlay

showGenerationProgress (lib/generation-progress.js), threshold-gated at 450ms. Click to run a fake ~2.5s staged "generation" and watch the bar appear/update/disappear.
